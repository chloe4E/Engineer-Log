## Key takeaways

- a bit is a single unit of information that can take only two values: 0 or 1 (base 2, 2 different possible values)
- a byte consists of 8 bits and can have 256 different combinations (2 to the power of 8 - 8 bits which can take two different values)
- binary is a counting system of base 2. Composed of 0s and 1s, the fundamental machine-readable code.
